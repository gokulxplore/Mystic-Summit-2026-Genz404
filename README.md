# GENZ CLUB — SIH26043 Prototype

A beginner-friendly front-end prototype for demonstrating a community challenge-to-solution workflow.

## Included portals
- Overview dashboard
- Citizen Portal: submit community challenges
- Verification Desk: review and update report status
- University Portal: submit solution proposals for verified challenges
- Industry Portal: register support interest for a proposal
- Government Dashboard: view counts, status breakdown, categories, and all reports

## Run the project
1. Download and extract `GENZ-CLUB-SIH26043.zip`.
2. Open the extracted `GENZ-CLUB-SIH26043` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension and click **Go Live**.
4. Start with Citizen Portal and submit a challenge.
5. Open Verification Desk and click **Mark verified**.
6. Open University Portal and submit a solution.
7. Open Industry Portal and register support.
8. Open Government Dashboard to see the updated activity.

## Files
- `index.html` — page structure and portal forms
- `style.css` — premium responsive visual design
- `app.js` — navigation, form handling, demo workflow, and browser storage

## Important prototype limitations
- Data is saved in the current browser using `localStorage`.
- Data is not shared between different devices or users.
- Login, real identity verification, server database, AI classification, maps, file uploads, notifications, and government integrations are not implemented.
- Use fictional demo data during presentations. Do not enter sensitive personal information.

This is a functional demonstration prototype, not a production government service. Confirm every feature against the official SIH26043 problem statement before final submission.
